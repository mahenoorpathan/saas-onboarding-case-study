# Client Onboarding Checklist

A reusable checklist for onboarding a new hotel client onto hotel management software. Tick each item before moving to the next stage.

## Stage 1: Kickoff
- [ ] Kickoff call scheduled with the hotel's main contact
- [ ] Client's requirements and goals discussed
- [ ] Client's questions and concerns answered
- [ ] Any custom changes beyond the standard setup noted
- [ ] Onboarding project created in Zoho

## Stage 2: Requirements
- [ ] Requirements form sent to the client
- [ ] Completed form received
- [ ] Room types and number of rooms confirmed
- [ ] Room rates confirmed
- [ ] Service charges confirmed
- [ ] Maximum guests per room confirmed
- [ ] Food and beverage menus and prices received

## Stage 3: Listing data
- [ ] Trivago listing reviewed
- [ ] Airbnb listing reviewed
- [ ] Expedia listing reviewed
- [ ] Differences between listings and the form flagged and resolved with the client

## Stage 4: Configuration
- [ ] Rooms and room types set up
- [ ] Rates entered
- [ ] Service charges applied
- [ ] Occupancy limits set
- [ ] Menus and menu prices entered
- [ ] Zoho project updated

## Stage 5: Testing
- [ ] Test booking made for each room type
- [ ] Prices and charges calculate correctly
- [ ] Occupancy limits work as expected
- [ ] Any issues fixed and re-tested

## Stage 6: Training
- [ ] User guides shared with hotel staff
- [ ] Staff walked through daily tasks
- [ ] Staff questions answered

## Stage 7: Go-live
- [ ] Client confirms they're ready
- [ ] Hotel goes live
- [ ] Client told how to request support (ticket system or email)
- [ ] Zoho project marked complete
